# Atlas v0.1.0：本地开发基线

首个稳定发行线采用 MIT，目标为单所有者 Apple Silicon macOS + OrbStack。
“稳定”限定于这里的开发契约，不表示生产、HA、独立 DR、多租户、自动恢复或任意旧版本升级。
正式仓库为 `snkio027/atlas`；原 Shell 项目保留在已归档的 `snkio027/atlas-legacy`。

## 交付范围

- 下载包包含 `atlas-install`、与可执行文件绑定的 `runtime.json`、配置示例、校验和及许可证。
  首装不需要源码、Go 或 Task；准备阶段按锁定摘要下载私有运行工具。
- D1 创建四节点开发平台，完成有限 Bootstrap 和持久 GitOps 交接，提供 Web/TLS、监控与 S3 基础。
- 源码中的 `atlas-platform` 提供类型化 Project/Workload/Binding、普通应用交付及平台维护入口。
  它目前不是下载包中的第二个预编译 CLI；需要按仓库说明构建。
- PostgreSQL、Redis、Kafka、Flink、Loki 与常驻管理/原生入口为显式 post-install 变更。
  发行包不自动启用全部数据服务，不包含当前实例凭据、CA 私钥或已封装密文。

安装步骤见[首装指南](../first-install.md)，业务接入见[普通应用交付](../application-delivery.md)，
现存实例的使用方式见[组件入口](../local-platform-access.md)。
